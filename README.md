# 工业数据智能入门指南

这是一份用中文编写的工业数据智能入门教材，使用 LaTeX 排版。它从数据、模型和损失函数讲起，逐步介绍概率推断、深度学习，以及在数据有限、工况变化或数据分散时如何学习。

**直接阅读：[完整 PDF](./main.pdf)** · **源码入口：[main.tex](./main.tex)**

本书讨论的不只是设备维护。工业中的数据任务还包括风功率预测、风场重建、缺失值填充、图像缺陷定位，以及根据手册和历史记录回答问题。设备维护是贯穿案例之一，用来解释预测时间、标签、误报和漏报等概念，并不是本书适用范围的全部。

## 适合谁读

- 刚接触机器学习、希望了解模型背后数学含义的学生。
- 熟悉设备、能源或生产业务，希望把实际问题写成学习任务的工程人员。
- 已经能够训练模型，但希望进一步理解目标函数、优化、泛化和不确定性的读者。

有基本的代数和函数知识会更容易上手。第一章补充向量、矩阵、概率和微积分的常用概念；遇到推导时，可以先用一维变量或少量样本算一遍，再阅读一般形式。

### 第三部分：核方法

本部分按知识依赖组织。先定义核、特征映射、特征函数、RKHS 和正定性，再说明核如何进入SVM对偶。随后在同一章中从确定性PCA过渡到PPCA和kPCA，最后讨论回归、在线学习与概率预测。

11. [支持向量回归](./chapters/09-svr.tex)：容忍带损失、原始与对偶问题、KKT 条件及算例。
12. [核最小均方](./chapters/09-klms.tex)：在线函数梯度、步长、字典控制与预测后更新的评价顺序。
13. [高斯过程回归](./chapters/09-kernel-gp.tex)：联合高斯条件化、函数与观测方差、KRR 联系及超参数。

新增的 KRR、SVR、KLMS 分别选自 Theodoridis 第 11.7、11.8、11.12.1 节。GP 保留为独立的概率补充。原合章稿 [09-kernel-algorithms.tex](./chapters/09-kernel-algorithms.tex) 保留但不再由主文档引入。

## 建议怎样阅读

**第一次系统学习**：先读前言中的设备预测例子，分清输入、标签、参数、训练、预测和决策，再按目录顺序读。每章先看要解决什么问题，再用正文中的小规模算例对照公式；不要只背结论。读完一节后，尝试不看公式说明输入是什么、每一步计算做了什么、输出能支持什么判断。不能解释的地方应回到对应定义和算例，而不是靠章末外部链接补齐正文。

**分两层读公式**：第一遍先掌握对象、输入输出和使用条件；第二遍检查符号、维度、中间推导与数值结果。较长推导不必一次记住，但不能把“暂时跳过推导”理解为结论无条件成立。不同章节的训练目标、数据可用时刻和评价对象可能不同，不能直接移用某一章的高分。

可读性修订的范围是主文档实际收录的23章及前言，按“初学者提出具体疑问—正文补充解释—再次核对算例与理解障碍”的方式逐章处理。在首轮修订基础上，又对23章分别进行了10轮审阅，共230个有效章节轮次；发现阅读覆盖不足的记录已单独补做并替代，不重复计数。十轮分别侧重先修与动机、术语、符号维度、推导步骤、算例、反例与边界、训练和推理操作、章节衔接、练习答案、完整复读及重复内容精简，不以机械增加篇幅作为完成标准。

上述23章、230轮及下文辅助材料的数量是此前版本的修订记录，不代表当前主文档的章节数量。当前主文档已按本目录调整为28章。未被主文档引入的历史稿和附加材料保存在 [chapters/archive/](./chapters/archive/)，不属于当前28章正文，未自动合并进正文。模拟读者复查不能替代真实读者的试读反馈；本次未重新验证外部学习资源链接及其统计信息。

**已经有实际任务**：先阅读第一部分，确定输入、目标、数据划分和评价指标，再进入对应章节。例如：

- 风功率或设备状态预测：学习流程、序列模型与不确定性分析。
- 风场重建：数学基础、概率方法与物理信息神经网络。
- 缺失值填充：数据工程、序列或生成模型；先辨别数据为什么缺失，以及填补时允许使用哪些观测。
- 图像缺陷定位：视觉模型；评价定位或分割误差，而不只看分类准确率。
- 设备连接与共同工序预测：图上的神经网络；先确认关系在预测时刻可用，再比较自身特征、成对图与超图模型。
- 手册问答：大语言模型；关注资料版本、检索依据与回答是否得到原文支持。
- 新设备少标签、工况持续变化或数据不能集中：按问题选读第四或第五部分。

这些是阅读入口，不代表某种模型对相应任务一定最好。先建立简单基线，再根据错误分析决定是否需要更复杂的方法。

## 页面与字号

版式参照 Goodfellow、Bengio 和 Courville 的英文版《Deep Learning》（花书）。[官方前置页 PDF](https://www.deeplearningbook.org/front_matter.pdf) 的页面为 7 × 9 英寸（177.8 × 228.6 mm），嵌入的正文字体包含 SFRM1095，对应约 10.95 pt。这里以 11 pt 文档基准字号排版中文正文，关闭 ctex 的默认中文字号覆盖，并使用 1.3 倍行距以改善中文与公式混排的可读性。此设置是相似版式，不是对中文译本不同印次字号的测定。

页面尺寸和版心在 [preamble.tex](./preamble.tex) 中设置：上边距 0.78 英寸、下边距 0.82 英寸、内侧 0.88 英寸、外侧 0.72 英寸，版心约 137.2 × 188.0 mm。内外边距适合双面装订。正文基准字号和行距在 [main.tex](./main.tex) 中设置，标题层级及其间距在导言区统一设置。

## 本地编译

### 环境要求

推荐安装较完整的 TeX Live 或 MiKTeX，并确保以下命令可以在终端中运行：

- XeLaTeX：处理中文与字体。
- BibTeX：生成参考文献。
- latexmk：自动安排编译轮次，更新目录与交叉引用。

文档使用 `ctexbook`，依赖中文排版支持，以及 AMS 数学宏包、TikZ、`algorithm`、`algpseudocode` 等。字体选择采用 `ctex` 默认设置；更换系统后若提示字体缺失，应先检查中文字体和 TeX 发行版的配置。

### 推荐命令

在项目根目录运行：

```powershell
latexmk -xelatex -synctex=1 -interaction=nonstopmode -halt-on-error main.tex
```

成功后打开 [main.pdf](./main.pdf)。latexmk 会按需要多次编译，以更新公式、图表、章节和参考文献的编号。

如果没有安装 latexmk，也可以依次运行：

```powershell
xelatex -synctex=1 -interaction=nonstopmode -halt-on-error main.tex
bibtex main
xelatex -synctex=1 -interaction=nonstopmode -halt-on-error main.tex
xelatex -synctex=1 -interaction=nonstopmode -halt-on-error main.tex
```

手动编译时，如果某一步失败，应先解决错误再继续。不要只运行一次 XeLaTeX 就判断引用是否完整。

### 在 Visual Studio Code 中编辑

可以安装 LaTeX Workshop 扩展，并选择使用 XeLaTeX 的构建方式。扩展不是命令行编译的必需条件。在章节文件中编辑时，应以 [main.tex](./main.tex) 作为编译入口，而不是单独编译章节文件。

## 内容维护约定

修改教材时，尽量保持以下约定：

- **语言具体**：用平实的中文解释问题，必要时举例，不用抽象口号代替技术说明。
- **术语准确**：英文技术缩写首次出现时先给出英文全称，再给出缩写。
- **推导完整**：交代假设、符号、关键步骤和适用条件，不只列最终公式，也不把近似写成严格等式。
- **引用明确**：正文使用已编号公式时用 `\eqref{...}`；每幅图、每张表都应有标签、正文引用及说明，不手写编号。
- **章节连贯**：开头说明问题与前文联系，结尾总结主要结论和下一步要解决的问题。
- **案例诚实**：新增教学例子应明确是举例或假设，不能写成已经完成的工业实验。
- **修改后检查**：重新编译，处理新增的未定义引用、重复标签、缺失字符和明显排版越界。

## 使用范围与说明

本项目是教材与推导材料，不是可直接部署的工业软件。书中的数值设置用于教学，不代表已完成的现场实验，也不构成对模型性能、安全性或经济收益的保证。

实际应用时，需要根据数据来源、预测时刻、缺失机制、现场约束和错误代价重新验证。模型输出的概率、重建结果或生成样本，都不能替代必要的测量、复检和专业判断。
